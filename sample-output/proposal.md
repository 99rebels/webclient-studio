## Project Summary

A full redesign of summitdentalcare.ie — modern, mobile-first, built to convert visitors into booked appointments. The new site will address the critical issues identified in our research: broken mobile experience, no online booking, slow load times, and outdated content.

## Scope of Work

### 1. Design & Development
- Custom responsive website built on a modern stack
- Mobile-first design — every page tested on mobile before desktop
- Clean, professional aesthetic matching the premium positioning of the practice
- Integration with their existing online booking system (or implementation of one)

### 2. Key Pages
| Page | Purpose |
|---|---|
| Home | Hero section, trust signals (reviews, certifications), clear CTA to book |
| Treatments | Service pages for general, cosmetic, and emergency dentistry |
| About the Practice | Team profiles, practice history, certifications |
| Book Online | Integrated booking page — the primary conversion goal |
| Contact | Location, phone, email, opening hours, map embed |

### 3. Technical Requirements
- Page load time under 3 seconds on mobile
- SSL certificate on all pages
- SEO-optimised page structure and meta tags
- Google Business profile integration (reviews displayed on site)
- CMS for blog posts and treatment updates
